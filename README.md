# Интерьер — интернет-магазин мебели

Многостраничный сайт интернет-магазина мебели с каталогом и корзиной.

## 🔗 Демо
[Посмотреть сайт](https://interier-shop.netlify.app/)

## 📎 Портфолио
[Посмотреть все работы](https://your-finances.tilda.ws)

## 📋 Страницы
- **Главная** — обложка, специальные предложения, каталог товаров, модальное окно корзины
- **Каталог** — фильтрация товаров по цене, цвету, типу комнаты и срокам доставки
- **Корзина** — оформление заказа, блок специальных предложений

## 📋 Что реализовано
- Адаптивная вёрстка (десктоп / планшет / мобилка)
- Модальное окно корзины на главной странице
- Фильтрация товаров в каталоге (радио-кнопки, чекбоксы, слайдеры)
- Слайдер для выбора цены
- Кастомные чекбоксы и радио-кнопки
- Работа с SVG-иконками
- Hover-эффекты на карточках товаров
- Компиляция SCSS в CSS

## 🛠️ Технологии
- HTML5
- CSS3 (Flexbox, Grid)
- SCSS
- JavaScript (ES6)
- Google Fonts (Montserrat, Poppins)

## 📁 Структура
- `index.html` — главная страница
- `testcat.html` — каталог
- `testcart.html` — корзина
- `style.css` / `catalog.css` — стили
- `style.scss` / `_cart.scss` — исходники SCSS
- `image/` — изображения
